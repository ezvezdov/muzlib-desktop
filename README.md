# Muzlib-desktop

Muzlib-desktop is a graphical user interface (GUI) for [muzlib](https://github.com/ezvezdov/muzlib), a music library manager.

# Installation

## Arch Linux \[AUR\]
You can install `muzlib-desktop` from AUR using your favorite AUR helper, for example:
```bash
yay -S muzlib-desktop
```

## From PyPI
Ensure that you have installed [FFmpeg](https://ffmpeg.org/download.html).

```bash
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
pip install muzlib-desktop
```

# Usage

Run `muzlib` or `muzlib-desktop` in your terminal.
You can also create a desktop shortcut for it.
